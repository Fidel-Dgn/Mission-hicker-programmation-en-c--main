# Mission-hicker-programmation-en-c--main
La mission Hiker consiste à détecter, compter et surveiller le passage de personnes (« hikers ») dans une zone donnée, en utilisant un télémètre ultrason HC‑SR04, un photo‑résistor, un bouton utilisateur, et une LED d’état. Le système fonctionne en autonomie grâce à une machine à états embarquée sur une carte STM32G431KB.
